# ウィルシー 仕様（第1段階）

## ねらい

気になったものを、見ているアプリからそのまま放り込む。整理はアプリがやる。あとで言葉で探せば出てくる。

## 1. 取り込み

- ほかのアプリの共有ボタン →「ウィルシー」を選ぶ。操作はこれだけ。
- 受け取るもの：Web ページの URL、文字、画像（1枚）。
- 画面の下に「保存しました」と約1秒出て、元のアプリに戻る。入力は求めない。
- 通信がなくても保存できる。解析は次にアプリを開いたときに行う。
- 同じ URL は二重に登録せず、一覧のいちばん上に戻す。
- アプリ内の「＋」から URL を直接足すこともできる。

## 2. 解析して登録

取り込んだ1件ごとに、次を付ける。

| 項目 | 決め方 |
| --- | --- |
| 共有元 | URL のサイト名（食べログ、YouTube、Instagram など）。画像は「写真・画像」、文字は「テキスト」 |
| ジャンル | 場所／商品／イベント／レシピ／作品／記事／動画／画像／メモ／書類 の10種類 |
| 取り込み日 | 共有した日時 |
| 題名・要約・サムネイル | ページの情報から。画像は写っている文字から |
| 場所（名前・住所・座標） | ページの情報、地図 URL の座標、写真の撮影場所、なければ名前や住所から検索 |
| 日付 | ページのイベント情報、なければ本文中の日付（イベントのみ） |

解析の順番：

1. ページに埋め込まれた情報（JSON-LD、OGP）。いちばん確実。
2. サイトごとの決まり（YouTube は動画、食べログは場所、など）。
3. 端末内AI。上で決まらなかったジャンル、要約、場所名、日付を埋める。使えない端末では省く。

ジャンルは詳細画面でいつでも手で直せる。

## 3. 予定とマップ

- 日付の付いたものは「予定」タブに自動で並ぶ（これから／終わったもの）。
  iPhone のカレンダーへは詳細画面のボタン1つで登録する（勝手には書き込まない）。
- 座標の付いたものは「マップ」タブにピンが立つ。ピンの色はジャンルの色。
  ピンを選ぶと下にカードが出て、詳細へ進める。詳細から経路を開ける。

## 4. 検索

- 「すべて」タブの検索欄に言葉を入れる。打つそばから結果が変わる。
- 意味の近さ（端末内の日本語モデルで作ったベクトル）と、言葉の一致を合わせて順位を付ける。
- モデルが用意できない端末では、言葉の一致だけで動く。
- すべて端末の中で行い、通信しない。

## 5. ジャンルの絞り込み

- 一覧の上に、入っているジャンルだけが並ぶ。1タップで切り替え、もう一度押すと解除。
- 検索と組み合わせられる。マップでも同じ絞り込みが使える。

## 6. 見た目

- 白と黒が基調。iPhone のライト／ダーク設定に従う。
- 色はジャンルごとに1色（場所＝緑、商品＝オレンジ、イベント＝ピンク、レシピ＝黄、作品＝青緑、
  記事＝青、動画＝赤、画像＝紫、メモ・書類＝グレー）。
- 一覧の1行には、題名・ジャンル・共有元・取り込み日（あれば日付）が必ず出る。
- 押すところは 44pt 以上。文字サイズの設定に従う。

## まだ入れていないもの

状態（気になる／行きたい／行った）、メモ、きっかけ、ふりかえり、通知、友人への共有、
アプリ不要の共有ページ、課金、iCloud 同期、写真ライブラリからの取り込み。
