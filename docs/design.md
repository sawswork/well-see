# ウィルシー 仕様（第1段階・改訂2）

## ねらい

気になったものを、見ているアプリからそのまま放り込む。整理はアプリがやる。あとで言葉で探せば出てくる。

## 1. 取り込み

- ほかのアプリの共有ボタン →「ウィルシー」を選ぶ。操作はこれだけ。
- 受け取るもの：Web ページの URL、文字、画像（1枚）。
- 画面の下に「保存しました」と約1秒出て、元のアプリに戻る。入力は求めない。
- 通信がなくても保存できる。解析は次にアプリを開いたときに行う。
- 同じ URL は二重に登録せず、一覧のいちばん上に戻す。
- アプリ内の「＋」から URL を直接足すこともできる。

## 2. 解析して登録

取り込んだ1件ごとに、次を付ける。

| 項目 | 決め方 |
| --- | --- |
| 共有元 | URL のサイト名（食べログ、YouTube、Instagram など）。画像は「写真・画像」、文字は「テキスト」 |
| ジャンル | 場所／商品／イベント／レシピ／作品／記事／動画／画像／メモ／書類 の10種類 |
| 取り込み日 | 共有した日時 |
| 題名・要約・サムネイル | ページの情報から。画像は写っている文字から |
| 場所（名前・住所・座標） | ページの情報、地図 URL の座標、写真の撮影場所、なければ名前や住所から検索 |
| 日付 | ページのイベント情報、なければ本文中の日付（イベントのみ） |

解析の順番：

1. ページに埋め込まれた情報（JSON-LD、OGP）。いちばん確実。
2. サイトごとの決まり（YouTube は動画、食べログは場所、など）。
3. 端末内AI。上で決まらなかったジャンル、要約、場所名、日付を埋める。使えない端末では省く。

ジャンルは詳細画面でいつでも手で直せる。

## 3. 予定とマップ

- 日付の付いたものは「予定」タブに自動で並ぶ（これから／終わったもの）。
  iPhone のカレンダーへは詳細画面のボタン1つで登録する（勝手には書き込まない）。
- 座標の付いたものは「マップ」タブにピンが立つ。ピンの色はジャンルの色。
  ピンを選ぶと下にカードが出て、詳細へ進める。詳細から経路を開ける。

## 4. 検索

- 「すべて」タブの検索欄に言葉を入れる。打つそばから結果が変わる。
- 意味の近さ（端末内の日本語モデルで作ったベクトル）と、言葉の一致を合わせて順位を付ける。
- モデルが用意できない端末では、言葉の一致だけで動く。
- すべて端末の中で行い、通信しない。

## 5. ジャンルの絞り込み

- 一覧の上に、入っているジャンルだけが並ぶ。1タップで切り替え、もう一度押すと解除。
- 検索と組み合わせられる。マップでも同じ絞り込みが使える。

## 6. 見た目

- 白と黒が基調。iPhone のライト／ダーク設定に従う。
- 色はジャンルごとに1色（場所＝緑、商品＝オレンジ、イベント＝ピンク、レシピ＝黄、作品＝青緑、
  記事＝青、動画＝赤、画像＝紫、メモ・書類＝グレー）。
- 一覧の1行には、題名・ジャンル・共有元・取り込み日（あれば日付）が必ず出る。
- 押すところは 44pt 以上。文字サイズの設定に従う。

## 改訂2で変えたこと（2026-11-26、実機で触った結果）

### 画面
- ホーム1画面にまとめる。タブと画面上部の題名はなくす。
- 画面の下に、分類 → ジャンル → 検索欄の順で置く。検索欄の右に、マップ・予定・追加の丸いボタンを並べる。
- 一覧の行を右へスワイプでピン留め（一覧のいちばん上に固定）、左へスワイプで削除。
- マップと予定は、ホームから開く画面にする。

### 題名と情報の統一
- 題名は「中身の名前」だけにする。サイト名（先頭の Amazon、末尾の | サイト名）は落とす。
  SNS の投稿は投稿者名ではなく、投稿の内容を表す題名にする（投稿者は詳細に出す）。
- 一覧の1行は、題名 ／ ジャンル・分類・共有元 ／ 取り込み日（と予定）で統一。
- 詳細の情報は、共有元 → 日付 → 場所 → 住所 → その内容ならではの項目（価格、評価、長さ、投稿者など）→ 取り込み日 の順で統一。

### 分類（ジャンルの中のカテゴリー）
- ジャンルの下に、もう一段の分類を持つ（記事の中の「アニメ」、場所の中の「寿司」など）。
- ジャンルを選ぶと、その中にある分類が絞り込みに出る。
- 分類は、ページの情報（料理の種類など）か端末内AIが付ける。言葉がばらつかないよう、すでに使っている分類を優先する。
- 公式サイトやお知らせのページは「記事」。「イベント」は、ページ自体が1つの催しを示しているときだけ。

### 予定
- ジャンルとは別に扱う。記事や動画でも、開催日や期間が書かれていれば予定に並ぶ。
- 投稿文や、サムネイル画像に書かれた文字（「2026年11月6日〜12月6日」など）からも日付を読む。
- 登録するのは、まだ終わっていないものだけ。過去の日付は予定にしない。
- 1日だけの日付は、近くに「開催」「まで」などの言葉があるときだけ採る（投稿日を拾わないため）。

### サムネイル
- OGP → ページの埋め込み情報 → 通販サイトの商品写真 → 本文の写真 → iPhone のリンクプレビュー → サイトのアイコン の順に探し、
  できるだけ全部に画像を出す。

### 検索
- 言葉の一致は、題名・分類・関連語・要約など中身を表す欄だけで見る。ページ全体の文字（メニューなど）は見ない。
- 端末内AIが付けた関連語（言い換えや上位の分類）も対象にする。
- 意味の近さ（ベクトル）で足すのは、全体の中で飛び抜けて近いものだけ。

### 場所
- 名前から座標を調べるとき、日本で使っている場合は日本の中だけを探す。

## 改訂3：ホームの並べ方（2026-11-26、持ち主が Gemini で作った参考画像に合わせる）

- いちばん上に、ジャンルごとのタイル（記号・名前・件数）を横に並べる。押すとそのジャンルだけになる。
- その下は区切りごとに並べる：これからの予定 → ピン留め → ジャンルごと。
  各区切りは3件まで出し、続きは「すべて見る」で開く。
- 場所だけは、横にめくるカードにする（ピン留めと削除は長押しのメニュー）。
- 1件はカードで表す。ふちの色がジャンルの色。
- ジャンルで絞り込んだとき・検索したときは、区切りなしでカードを縦に並べる。
- 画面の下の操作（分類・ジャンル・検索欄・マップ・予定・追加）は今のまま。
- 参考画像にあった上部の題名、設定・通知のボタン、「AI Auto-analyzed」の印は入れていない。

## まだ入れていないもの

アプリ不要の共有ページ、課金、iCloud 同期、写真ライブラリからの取り込み。
